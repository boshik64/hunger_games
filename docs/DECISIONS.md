# Решения

- `pendingItem`, `pendingStrategy`, `isDrawing` и `isTransitioning` не пишутся в `sessionStorage`: после перезагрузки выбор нужно сделать заново, анимация жеребьёвки не продолжается.
- Если при загрузке дистрикт уже есть, `drawn` становится `true` — жеребьёвка считается раскрытой, повторных событий нет.
- Битый результат без предмета или стратегии откатывается на экран предмета; стратегия без предмета — тоже на предмет; шаг дальше жеребьёвки без дистрикта — на жеребьёвку. Сами поля при откате не стираются.
- Запись `kg:v1` с другой версией или неподходящей схемой удаляется, сессия начинается с жеребьёвки.
- Характеристика не хранится в сторе: её всегда даёт пара `item:strategy` из `RESULTS`.
- Подтверждение предмета синхронное. `isTransitioning` включается только на переходе со стратегии к результату и снимается вызовом `endTransition`.
- Названия и фразы характеристик лежат в `ru.ts`. Дословные объяснения шести комбинаций — в `results.ts`.
- Текст «Выбрать сеанс» и «Скачать карточку» задан один раз и используется на всех кнопках с этой подписью.
- Футер — одна строка: «12+ · Голодные игры: Рассвет жатвы · Правообладатель/дистрибьютор».
- `base` сборки — `'./'`, чтобы статические файлы открывались из подкаталога.
- Жеребьёвка идёт через `crypto.getRandomValues` и rejection sampling. Если `crypto` нет или 16 значений подряд попали в отброшенный хвост — `Math.random`.
- Гидратация стора ручная (`skipHydration`): приложение ждёт её и только потом показывает текст.
- `addActiveTime` копит время, пока вкладка видима. События шагов уходят из действий стора, клики — из кнопок. `completedAttempts` пополняется в момент входа на результат.
- Фон экрана — один финальный кадр из материалов прокатчика. Гербы дистриктов и иконки предметов оригинальные: в поставке их не было. Наборное «КАРО» стоит, пока нет официального SVG.
- «Выбрать сеанс» ведёт на страницу фильма КАРО. Цвет титров интерфейса взят с постера: сирень `#e0c0d8` и белый `#f7f5f3`. Шаг помещается в один экран, без прокрутки внутри кадра.
- Дистрибьютор в футере — АТМОСФЕРА КИНО. «Пройти ещё раз» начинает жеребьёвку заново. Клики пишутся в `data/clicks.json` и в `localStorage` `kg:stats:v1`. На карточке гостя нет адреса сайта.
